# Google Stitch : agent IA temps réel pour le design UI

Google a présenté à Google I/O 2026 (20 mai) deux mises à jour majeures de **Stitch**, son outil de design UI natif IA disponible via Google Labs : un agent en streaming temps réel, et l'édition collaborative multi-utilisateur. Les deux fonctionnalités sont disponibles gratuitement.

## De tour par tour au streaming continu

L'évolution la plus marquante est architecturale. L'ancienne version de Stitch fonctionnait sur un modèle tour par tour : vous soumettez un prompt, vous attendez que la génération se termine, vous voyez le résultat. La mise à jour remplace ce workflow par un **agent en streaming continu** : les composants UI se dessinent directement sur le canvas pendant que vous écrivez ou parlez.

L'intégration vocale est au cœur de ce nouveau mode : vous pouvez dicter des instructions comme « donne-moi trois versions du menu de navigation » et regarder le canvas évoluer en temps réel pendant que vous parlez. Le modèle sous-jacent est la famille Gemini de Google.

## Collaboration multi-utilisateur

Stitch intègre désormais l'**édition simultanée multi-utilisateur**, une fonctionnalité qui faisait jusqu'alors défaut. Google compare explicitement l'expérience à celle de Google Docs : plusieurs designers ou développeurs peuvent modifier le même fichier en simultané, voir les curseurs des autres et les modifications en direct.

## Disponibilité et positionnement

Les deux fonctionnalités — l'agent streamé et le multi-joueur — sont disponibles **gratuitement** pour tous les utilisateurs dans le monde via Google Labs. Stitch fonctionne sur la famille Gemini.

Google positionne explicitement Stitch comme une alternative à Figma, dont le plan professionnel standard est facturé 15 $/éditeur/mois. C'est un positionnement à prendre avec nuances : Stitch n'est pas un outil de handoff ou de fidélité visuelle comme Figma, c'est un outil de génération et d'idéation UI rapide. Complémentaire pour la phase d'exploration, pas encore substituable pour les équipes design établies qui gèrent des design systems complexes.

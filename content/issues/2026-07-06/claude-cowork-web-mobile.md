# Claude Cowork quitte le desktop pour le cloud

À partir du 7 juillet 2026, Anthropic déploie Claude Cowork — jusque-là limité à l'application desktop — vers le web et le mobile, en priorité pour les abonnés du plan Max. Le changement d'architecture est le point central de l'annonce : une tâche lancée sur ordinateur portable peut désormais continuer à s'exécuter dans le cloud après la fermeture de la machine, et être consultée ou reprise plus tard depuis un téléphone ou un navigateur. Chat et Cowork partagent maintenant un même espace, avec projets et artefacts synchronisés entre appareils.

## Un usage très majoritairement non-codant

Anthropic a profité de cette annonce pour partager des données d'usage inédites : plus de 90% de l'utilisation de Cowork concerne des tâches qui ne relèvent pas du code — opérations d'entreprise, création de contenu, organisation de projet. C'est une information notable pour qui associe spontanément Anthropic à Claude Code : Cowork s'affirme comme un produit d'agent généraliste pour le travail de connaissance au sens large, plutôt que comme une extension du développement logiciel.

## Des limites d'usage doublées jusqu'au 5 août

Pour accompagner ce déploiement élargi, Anthropic double temporairement les limites d'usage de Cowork jusqu'au 5 août 2026 — une incitation classique de lancement destinée à encourager l'adoption pendant la phase de montée en charge cross-device.

Pour un développeur déjà utilisateur de Claude Code, cette extension de Cowork au web et au mobile élargit la surface d'usage d'Anthropic au-delà du poste de travail, en direction d'un usage d'agent "toujours actif" — une tendance qu'on retrouve également chez OpenAI avec le lancement conjoint de ChatGPT Work et de la nouvelle app Codex la même semaine.

# Codex intègre l'app ChatGPT unifiée sur desktop

Le 9 juillet 2026, en même temps que le lancement de GPT-5.6 et de ChatGPT Work, OpenAI a annoncé la fusion de Codex dans une application ChatGPT desktop unique pour macOS et Windows, qui regroupe désormais Chat, Work et Codex dans une seule interface. L'ancienne application ChatGPT desktop est renommée "ChatGPT Classic". Cette nouvelle app est disponible sur tous les plans, y compris l'offre gratuite — une ouverture notable pour un outil de codage agentique jusque-là plus segmenté par plan.

## Diff inline et revue de PR sans changer de contexte

Concrètement, l'intégration apporte l'édition de diff inline directement dans l'app, ainsi qu'un panneau latéral pour la revue de pull request sans quitter ChatGPT — un flux qui rapproche l'expérience de celle d'un IDE augmenté plutôt que d'un simple chat avec exécution de code en arrière-plan. L'app gère également des projets multi-dépôts, permettant de faire travailler l'agent sur plusieurs repositories dans un même contexte de projet.

## Un Computer Use accéléré par GPT-5.6

L'intégration profite directement de la sortie de GPT-5.6 le même jour : les capacités de Computer Use de Codex — l'automatisation d'actions dans une interface graphique — sont annoncées comme plus rapides grâce au nouveau modèle. Ce couplage entre le lancement du modèle et la refonte de l'app confirme qu'OpenAI traite désormais Codex comme un produit de plateforme à part entière, aligné sur le rythme de sortie de ses modèles plutôt que comme une fonctionnalité annexe de ChatGPT.

Pour un développeur qui alterne déjà entre plusieurs agents de code, cette unification simplifie l'accès à Codex sans changement d'abonnement, et rapproche encore un peu plus l'expérience "agent de code intégré à l'éditeur" du grand public, gratuit inclus.

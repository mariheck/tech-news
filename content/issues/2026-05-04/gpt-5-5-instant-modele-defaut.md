# GPT-5.5 Instant : le nouveau modèle par défaut

Le 5 mai 2026, OpenAI a déployé **GPT-5.5 Instant** comme nouveau modèle par défaut pour l'ensemble des utilisateurs de ChatGPT, remplaçant GPT-5.3 Instant. Le changement est effectif pour tous les niveaux d'abonnement, y compris le plan gratuit.

## Des hallucinations significativement réduites

L'amélioration la plus substantielle de GPT-5.5 Instant porte sur la fiabilité factuelle :

- **52,5 % moins d'affirmations hallucination** sur les prompts à fort enjeu (médecine, droit, finance)
- **37,3 % de réduction des affirmations inexactes** sur les conversations signalées par les utilisateurs

Ces chiffres ont été mesurés en comparaison directe avec GPT-5.3 Instant sur les mêmes jeux de prompts. OpenAI souligne que le gain est particulièrement notable sur les sujets où la précision factuelle est critique.

## Un ton plus concis et pratique

Au-delà de la fiabilité, GPT-5.5 Instant adopte un registre délibérément plus direct :

- **30,2 % moins de mots** en sortie
- **29,2 % moins de lignes**

Le modèle répond de façon plus informelle et pratique, sans les reformulations et sur-explications caractéristiques des versions précédentes. L'objectif affiché est de privilégier l'utilité immédiate sur l'exhaustivité démonstrative.

## Memory sources : transparence sur la mémoire

GPT-5.5 Instant introduit une nouvelle fonctionnalité de transparence : **memory sources**. Elle permet aux utilisateurs de voir quelles conversations passées, fichiers sauvegardés ou données Gmail ont influencé une réponse donnée. Chaque source peut être consultée, corrigée ou supprimée individuellement.

La fonctionnalité est un pas vers une mémoire explicable et contrôlable — notamment pour les utilisateurs qui ont activé la mémoire persistante et connecté des services externes comme Gmail.

La **personnalisation Gmail améliorée** est déployée en priorité pour les abonnés Plus et Pro sur le web.

## Transition

GPT-5.3 Instant reste disponible dans les paramètres de modèle de ChatGPT **pendant encore trois mois** avant sa mise à la retraite, pour les utilisateurs qui souhaitent comparer les comportements ou maintenir une continuité sur des workflows existants.

Les projets utilisant GPT-5.3 Instant via l'API ne sont pas automatiquement migrés : le changement de défaut concerne uniquement l'interface ChatGPT. Les appels API continuent de pointer vers le modèle explicitement spécifié.

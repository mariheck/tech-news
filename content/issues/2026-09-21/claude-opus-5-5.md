# Claude Opus 5.5 : Anthropic mise sur l'efficacité

Le 22 septembre 2026, Anthropic a lancé **Claude Opus 5.5**, premier modèle de la nouvelle famille 5.5, disponible immédiatement via l'API Anthropic, Amazon Bedrock, Google Cloud Vertex AI et Microsoft Foundry (Azure).

## Des performances proches de Fable 5.1, à moindre coût

Anthropic positionne Opus 5.5 comme un modèle qui **égale les performances de Claude Fable 5.1 sur la plupart des tâches**, tout en coûtant **40 % de moins** à l'usage que l'ancien Opus 5. La vitesse de génération progresse également, avec une sortie de tokens en hausse de plus de **30 %**.

## Tarification et capacités

| Caractéristique | Valeur |
| --- | --- |
| Tarif entrée / sortie | 4 $ / 20 $ par million de tokens (-20 % vs Opus 5) |
| Cache reads | 0,20 $ / million de tokens (-60 %) |
| Fenêtre de contexte | 1 million de tokens |
| Sortie maximale | 128 000 tokens |
| Cutoff de connaissances | Juin 2026 |

Cette baisse de prix combinée à la fenêtre de contexte élargie rend Opus 5.5 particulièrement pertinent pour les usages de développement assisté par IA à gros volume de contexte : bases de code entières, longues sessions d'agent.

## Disponibilité multi-cloud dès le lancement

Contrairement à certains lancements historiquement réservés dans un premier temps à l'API Anthropic, Opus 5.5 est disponible **dès le jour 1** sur les trois grands clouds partenaires, simplifiant son adoption pour les entreprises déjà engagées sur l'un de ces écosystèmes.

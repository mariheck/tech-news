# Motion Studio : l'agent qui édite l'animation en direct

Le 22 septembre 2026, Motion (l'ex-Framer Motion) a annoncé **Motion Studio**, un éditeur visuel et agentique pour les animations web, disponible en plugin pour Vite, Webpack et Next.js.

## Ultramotion : un agent qui édite un modèle de données, pas du code

Le cœur de Motion Studio est **Ultramotion**, un agent d'édition bâti sur deux modèles internes (nommés Jev et Luna) qui applique les changements **directement à un modèle de données d'animation**, plutôt que de générer et relire du code à chaque itération. Résultat annoncé : des éditions appliquées en **moins d'une seconde**, un temps de boucle très inférieur à celui d'un agent de code classique qui doit écrire, sauvegarder et recompiler.

## Gratuit pour l'aperçu, payant pour l'écriture dans le code

L'aperçu de Motion Studio et son installation locale sont gratuits. En revanche, les éditions agentiques d'Ultramotion et l'écriture des changements directement dans le code source du projet nécessitent un abonnement payant.

## Pourquoi ça compte pour les devs frontend

Motion Studio s'inscrit dans une tendance émergente d'éditeurs "agent-first" pour des domaines très spécifiques — ici, l'animation web — plutôt que des agents de code généralistes. En couplant un modèle de données propre à l'animation avec un agent dédié, Motion mise sur une boucle d'itération plus rapide que celle des agents de code généralistes appliqués à des fichiers CSS/JS classiques.

# Copilot : paliers de modèles et revue qui se souvient

GitHub a publié le 18 septembre 2026 son billet hebdomadaire de changelog pour GitHub Copilot, couvrant les livraisons de la semaine démarrée le 14 septembre.

## Choisir son compromis vitesse/qualité

VS Code, la CLI Copilot et l'application Copilot reçoivent tous trois de nouveaux paliers de sélection de modèle, organisés autour de trois profils : *efficiency*, *balance* et *intelligence*. L'objectif est de laisser l'utilisateur arbitrer explicitement entre rapidité de réponse et qualité du résultat plutôt que de choisir un modèle nommé sans repère de positionnement.

## Une revue de code qui garde le fil

Copilot Code Review gagne la capacité de résoudre automatiquement, lors des revues suivantes sur la même pull request, les commentaires déjà traités par le développeur — évitant de re-signaler un problème déjà corrigé. L'outil suggère désormais également des messages de commit.

## VS Code Agents en disponibilité générale

La fenêtre "VS Code Agents", qui affiche des métriques d'usage des agents directement dans l'éditeur, passe en disponibilité générale après une période en preview.

## Pourquoi ça compte

Pris isolément, aucun de ces changements ne constitue une rupture. Mais l'accumulation hebdomadaire de ce type d'ajustements — paliers de modèles, mémoire des revues, métriques d'usage — dessine la manière dont GitHub affine en continu Copilot comme outil de production plutôt que comme simple autocomplétion, au rythme d'un concurrent direct de Claude Code et Cursor sur le terrain des agents de code intégrés à l'éditeur.

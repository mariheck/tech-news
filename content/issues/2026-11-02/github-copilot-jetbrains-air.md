# GitHub Copilot débarque dans JetBrains Air

GitHub a annoncé le 3 novembre 2026 que **GitHub Copilot** est désormais disponible comme agent par défaut dans **JetBrains Air**, l'environnement de développement agentique de JetBrains.

## Un agent de plus dans un IDE multi-agents

L'intégration s'appuie sur l'**Agent Client Protocol (ACP)**, le protocole ouvert qui permet à un IDE de brancher plusieurs agents de code interchangeables — Air accueillait déjà d'autres agents compatibles ACP. Copilot est disponible à la fois via l'exécution locale (Local Run) et via l'exécution dans le cloud (Cloud Run) de Air. GitHub précise que la version dans Air couvre les usages agentiques de base (sélection de modèle, sessions en parallèle), mais que le plugin Copilot dédié conserve des fonctionnalités avancées absentes de cette intégration, comme les personnalisations et les journaux de debug des agents.

## Pourquoi ça compte

Pour un développeur qui jongle entre plusieurs assistants de code, cette intégration confirme la bascule de l'écosystème vers des IDE "porte-agents" neutres plutôt que vers un outil propriétaire unique — Copilot y devient une option parmi d'autres plutôt qu'un choix exclusif.

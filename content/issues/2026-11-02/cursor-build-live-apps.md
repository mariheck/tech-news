# Cursor peut déployer une app depuis le chat

Cursor a annoncé le 5 novembre 2026 **Build Live Apps**, une fonctionnalité qui permet de construire et déployer une application complète directement depuis le chat de l'éditeur, sans quitter l'outil.

## De la description au lien partageable

À partir d'une description en langage naturel, l'agent de Cursor prend en charge la construction de l'app, la configuration d'une base de données et de l'authentification, puis le déploiement sur un **domaine unique et un lien partageable**. La fonctionnalité passe par les agents cloud de Cursor — elle n'est pas disponible pour les agents exécutés en local — et chaque app déployée passe par une revue de sécurité automatique avant publication, pour bloquer les problèmes les plus sérieux.

## Pourquoi ça compte

Pour un développeur qui veut prototyper rapidement une démo ou un outil interne sans monter toute la chaîne de déploiement à la main, cette fonctionnalité rapproche Cursor d'une plateforme d'app complète plutôt qu'un simple éditeur assisté par IA.

# GitHub Copilot : sandboxing local en version stable

Dans ses notes de version hebdomadaires du 9 octobre 2026, GitHub a annoncé deux changements pour **Copilot**. D'abord, **Claude Haiku 5.5** devient disponible pour les forfaits Pro, Pro+, Max, Business et Enterprise. Ensuite, et surtout, le **sandboxing local** passe en disponibilité générale dans le Copilot CLI, l'application Copilot et l'Agent Host de VS Code — sans coût supplémentaire.

## Isoler l'exécution de l'agent

Le sandboxing local permet de contenir l'exécution des actions d'un agent Copilot sur la machine de l'utilisateur, un point sensible alors que ces agents gagnent en autonomie sur le poste de développement.

## Du côté des administrateurs JetBrains

Le 10 octobre, GitHub a aussi annoncé que les administrateurs d'entreprise peuvent désormais choisir n'importe quel modèle d'agent Copilot disponible comme modèle par défaut pour les nouvelles conversations dans **Copilot for JetBrains**.

## Pourquoi ça compte

Le passage du sandboxing en disponibilité générale, sans surcoût, abaisse la barrière à l'exécution sécurisée d'agents de code en local — un sujet de plus en plus central à mesure que ces agents sont autorisés à exécuter des commandes directement sur la machine du développeur.

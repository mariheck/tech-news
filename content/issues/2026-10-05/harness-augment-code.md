# Harness rachète Augment Code pour ses agents IA

Harness a annoncé le 8 octobre 2026 l'acquisition d'actifs sélectionnés d'**Augment Code**, start-up connue pour son agent de codage. Le montant de l'opération n'a pas été divulgué.

## Ce qui change de mains

L'opération porte sur trois éléments : **Cosmos**, l'agent d'Augment Code, rebaptisé « **Harness Cosmos Software Factory Agent** » ; l'**Auggie CLI** ; et le **Code Context Engine**, le moteur de compréhension de code d'Augment.

## L'ambition affichée

Harness présente cette acquisition comme une étape vers l'automatisation de bout en bout du développement logiciel — de la génération de code jusqu'à la livraison, un terrain où l'entreprise opère déjà via sa plateforme de delivery.

## Pourquoi ça compte

C'est un nouveau mouvement de consolidation dans l'écosystème des agents de code IA : les plateformes DevOps établies rachètent des équipes d'agents plutôt que de les construire en interne, un signe que la bataille se joue aussi sur l'intégration avec les chaînes de livraison existantes.

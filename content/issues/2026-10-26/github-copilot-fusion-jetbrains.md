# Copilot Fusion débarque sur JetBrains

Le 28 octobre 2026, GitHub a déployé **Copilot Fusion** sur les IDE JetBrains, dans le cadre des releases Universe de Copilot pour JetBrains. Fusion remplace l'ancienne option de modèle **« Auto »**.

## Un routage automatique entre modèles

Là où le mode « Auto » sélectionnait un modèle selon des règles simples, Fusion route chaque requête vers le modèle le plus adapté à la tâche en cours — complétion rapide, refactoring, ou raisonnement plus poussé — sans action de l'utilisateur.

## Pourquoi ça compte

Pour les développeurs sur JetBrains, Fusion supprime l'arbitrage manuel entre modèles rapides et modèles plus capables : le routage automatique vise à donner la meilleure réponse pour chaque requête, au lieu d'un compromis unique appliqué à toutes les tâches.

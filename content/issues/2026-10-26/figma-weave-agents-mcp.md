# Figma Weave accessible aux agents IA via MCP

Le 26 octobre 2026, Figma a ouvert l'accès aux modèles de génération vidéo et image de **Weave**, sa plateforme de génération créative, via le serveur **MCP** de Figma. Un agent IA peut désormais déclencher une génération Weave comme n'importe quel autre outil exposé par le protocole.

## De la génération manuelle à l'outil d'agent

Jusqu'ici, Weave se pilotait depuis l'interface Figma. L'exposer via MCP permet à un agent de code ou de design — dans un éditeur, un assistant, ou un workflow automatisé — d'invoquer la génération vidéo ou image de Weave en tâche de fond, sans passer par l'interface graphique.

## Pourquoi ça compte

Pour les équipes qui orchestrent déjà des agents de design via MCP, cette ouverture ajoute une capacité générative directement dans la chaîne d'outils : un agent peut désormais produire un asset visuel au même titre qu'il manipule des calques ou des composants Figma.

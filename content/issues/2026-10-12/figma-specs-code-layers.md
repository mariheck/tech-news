# Figma ouvre Specs et Code Layers en bêta

Le 15 octobre 2026, lors de **Config India** à Bengaluru — la plus grande conférence Figma organisée à ce jour, avec plus de 30 000 inscrits — le CEO Dylan Field a annoncé deux nouveautés produit.

## Specs, un canvas Markdown pour les agents IA

**Specs** entre en bêta ouverte : un document canvas rédigé en Markdown, pensé pour servir de contexte à des agents IA, intégrable via MCP et GitHub.

## Code Layers passe en bêta publique

**Code Layers**, jusqu'ici réservé à une bêta privée, devient accessible en bêta publique à tous les utilisateurs.

## Pourquoi ça compte

Figma positionne ces deux outils comme des ponts entre design et code généré par IA, dans un contexte où le MCP s'impose comme langage commun entre outils de design et agents de développement.

# Mentions légales

## Présentation

Le site `tech.news` a été développé pour un usage personnel et est présenté ici comme projet de portfolio. Les contenus et le code source sont libres d'accès.

- **Textes** : Générés via une routine Claude Code, à partir d'actualités publiques disponibles sur le web. Les sources utilisées sont toutes citées.
- **Illustrations** : Générées via l'API de [leonardo.ai](https://app.leonardo.ai/), avec le modèle `gpt-image-2` et un prompt unique variabilisé.
- **Code source** : Le code source est disponible publiquement sur GitHub.

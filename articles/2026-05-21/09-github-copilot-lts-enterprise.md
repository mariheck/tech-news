# GitHub Copilot Enterprise bascule sur GPT-5.3-Codex LTS

Le 17 mai 2026, GitHub a complété le déploiement automatique de **GPT-5.3-Codex** comme modèle de base pour tous les plans Copilot Business et Copilot Enterprise. C'est la première fois que Copilot dispose d'un modèle en mode **LTS (Long-Term Support)** — une approche qui répond directement aux demandes des équipes enterprise en matière de stabilité et de prévisibilité.

## Qu'est-ce qu'un modèle LTS pour Copilot ?

Le LTS de GPT-5.3-Codex garantit que ce modèle restera disponible dans GitHub Copilot pendant **au moins 12 mois** à compter de sa date de lancement, soit jusqu'au **4 février 2027**. Pendant cette fenêtre, les organisations peuvent :

- Conduire leurs audits de sécurité et de conformité sur un modèle stable
- Planifier leurs workflows et intégrations sans risque de régression liée à un changement de modèle sous-jacent
- Calibrer leurs équipes sur un comportement de modèle cohérent

Le déploiement a été annoncé le 18 mars 2026 avec un délai de 60 jours pour la bascule automatique sur tous les plans éligibles — ce délai s'est écoulé le 17 mai.

## Ce qui change (et ce qui ne change pas)

**Pour les développeurs au quotidien** : GPT-5.3-Codex était déjà le modèle recommandé pour Copilot depuis février 2026 et disponible sur toutes les plateformes (github.com, GitHub Mobile, Visual Studio, VS Code, JetBrains). La bascule du 17 mai est essentiellement une migration administrative pour les organisations qui n'avaient pas encore basculé manuellement.

**Pour les équipes enterprise** : C'est la fin de l'incertitude sur le modèle de base. Les DSI et les équipes sécurité peuvent désormais s'appuyer sur une fenêtre de stabilité connue pour leurs processus de validation interne.

**Ce qui ne change pas** : Les plans Copilot Pro, Copilot Pro+ et Copilot Free ne sont pas concernés par cette migration LTS. Ils continuent de recevoir les mises à jour de modèles selon le rythme habituel.

## La refonte de la facturation au 1er juin

En parallèle du changement de modèle, GitHub prépare une **refonte majeure de sa facturation** effective au 1er juin 2026. Le modèle actuel (basé sur les "Premium Requests Units") laisse place à un système d'**AI Credits** :

- **1 AI Credit = $0.01 USD**
- Chaque plan inclut un quota mensuel d'AI Credits correspondant au prix de l'abonnement
- L'usage est calculé sur la consommation de tokens (input + output + cache)
- **Les complétions de code et Next Edit Suggestions restent illimitées** et ne consomment pas d'AI Credits

Le multiplicateur de GPT-5.3-Codex est de **1x** (c'est-à-dire que ce modèle consomme les AI Credits au tarif de base, sans surcoût).

Depuis début mai, GitHub a déployé un outil de **prévisualisation de facture** dans le Billing Overview de github.com, permettant aux organizations de simuler leur consommation avant la bascule du 1er juin.

## Pourquoi ça compte : la stabilisation de l'outillage IA

Au-delà des détails techniques, la semaine du 17 mai illustre une tendance de fond : **la professionnalisation de l'outillage IA pour le développement**. Après deux ans de rotation rapide des modèles et de pricing instable, les grandes plateformes (GitHub, Anthropic, OpenAI) convergent vers des offres enterprise plus structurées, avec des SLA, des LTS et des prédictibilités de coûts.

Pour les équipes qui adoptent Copilot à grande échelle, c'est un signal positif : l'outil sort de la phase "beta perpétuelle" pour entrer dans une logique de produit enterprise mature.

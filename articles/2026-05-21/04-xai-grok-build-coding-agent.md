# xAI entre dans la course des agents de code avec Grok Build

Le 14 mai 2026, xAI — la société d'IA d'Elon Musk — a lancé **Grok Build** en beta privée, un outil en ligne de commande positionné directement contre Claude Code d'Anthropic et Codex CLI d'OpenAI. Le marché des agents de code autonomes, en pleine consolidation, accueille ainsi un nouvel entrant avec des ressources significatives.

## Un CLI agentic conçu pour les tâches complexes

Grok Build s'installe dans un dossier de projet et reçoit des instructions en langage naturel. Comme ses concurrents, il peut explorer l'architecture d'un dépôt, expliquer du code existant, puis passer à des tâches comme l'ajout de rate limits à une API ou la refactorisation d'un module entier.

Deux caractéristiques techniques ressortent de l'annonce :

**8 sous-agents parallèles** : Grok Build peut déployer jusqu'à 8 agents en simultané, chacun travaillant sur une branche distincte du code. Cette parallélisation est conçue pour accélérer les tâches longues où les dépendances entre fichiers sont limitées.

**Mode plan obligatoire** : avant toute modification de fichier, l'outil génère un plan d'action et attend l'approbation explicite de l'utilisateur. Ce choix de design — identique à celui de Claude Code — reflète une décision de l'écosystème : les agents de code doivent être prévisibles avant d'être rapides.

## Benchmarks et positionnement

Le modèle sous-jacent de Grok Build score **70,8 % sur SWE-Bench Verified**, le benchmark de référence pour les agents de code. C'est dans la fourchette des offres concurrentes actuelles, sans toutefois dominer le classement : à titre de comparaison, Claude Opus 4.7 (Adaptive) atteint 87,6 % et Claude Mythos Preview 93,9 % sur la même référence.

Le positionnement de xAI n'est donc pas la performance brute mais l'accessibilité dans l'écosystème Grok, et potentiellement le coût à terme.

## Accès et tarification

La beta est réservée aux abonnés **SuperGrok Heavy**, l'offre premium à 300 $/mois. Un tarif d'introduction de 99 $/mois pour les six premiers mois est proposé aux early adopters — soit une remise de 67 %.

Cette stratégie de lancement en accès restreint est cohérente avec celle d'Anthropic au lancement de Claude Code : commencer par des utilisateurs avancés pour itérer rapidement avant une ouverture plus large.

## Un marché en pleine ébullition

La semaine du 11 au 17 mai 2026 illustre à elle seule la vitesse d'évolution du secteur : ServiceNow Build Agent s'étend à Cursor, Windsurf, Claude Code et GitHub Copilot ; Notion ouvre son External Agent API aux agents externes ; et xAI lance Grok Build. Le marché des agents de code cesse d'être un duopole Anthropic/OpenAI.
